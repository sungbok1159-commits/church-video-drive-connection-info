개인용 도구 · 2026년 10월 6일

개인정보 및 데이터 처리 안내

이 안내는 ‘교회 영상 편집 Drive 연결’의 Google Drive 파일 연결 기능에 관한 설명입니다.

사용하는 정보와 목적

본인 계정 확인을 위한 이메일 주소, Drive 저장 용량, 지정한 작업 폴더의 파일 이름·내용·크기·해시·수정 정보와 공유 상태를 사용합니다. 여러 Windows PC 사이에서 편집 자료를 복사하고 무결성, 비공개 상태와 작업 진행 상황을 확인하기 위한 목적입니다.

접근 범위

기존 작업 파일의 조회·다운로드·업로드를 위해 Google 권한 화면에는 Drive 파일에 대한 넓은 접근 권한이 표시될 수 있습니다. 도구의 실제 작업 대상은 사용자가 지정한 편집 폴더이며, 다른 Drive 자료의 전체 미러링이나 원본 삭제를 기본 동작으로 수행하지 않습니다. AI가 사용자의 요청에 따라 이 연결 도구를 실행합니다.

보관과 전달

영상·프로젝트·검수 이력과 인계 자료는 본인의 Drive와 작업 PC에, 코드·프롬프트·공통 기준은 본인의 비공개 GitHub 저장소에 보관합니다. 인증정보는 작업 PC의 암호화 저장소에 보관하며 GitHub·Drive·공개 웹페이지에 올리지 않습니다. 이 공개 안내 사이트에는 편집 자료를 저장하지 않습니다.

환경 연결 작업만으로 음성 분석 서비스에 자료를 보내지 않습니다. 별도의 음성 분석·외부 전송은 사용자가 허용한 편집 업무와 해당 서비스의 설정·권한 범위에서 따로 다룹니다.

사용자의 제어

사용자는 Google 계정의 타사 연결 관리에서 이 앱의 권한을 철회할 수 있습니다. Drive 파일과 로컬 작업 사본은 사용자가 직접 관리하며, 인증 철회만으로 보존한 편집 자료를 자동 삭제하지 않습니다. 지원·권한 문의는 Google 동의 화면에 표시되는 개발자 연락처를 이용합니다.
